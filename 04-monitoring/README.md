# 项目三：企业级监控告警系统

## 项目背景

为公司搭建统一监控告警平台，覆盖：
- 基础设施监控（服务器、网络、存储）
- 容器平台监控（K8S集群、Pod、容器）
- 应用性能监控（APM）
- 业务指标监控
- 日志监控与分析

## 监控指标体系

### 基础设施层
| 指标 | 采集方式 | 告警阈值 |
|------|----------|----------|
| CPU使用率 | node_exporter | > 85% 持续5分钟 |
| 内存使用率 | node_exporter | > 85% 持续5分钟 |
| 磁盘使用率 | node_exporter | > 80% |
| 磁盘IO | node_exporter | IO util > 90% |
| 网络流量 | node_exporter | > 带宽80% |
| 系统负载 | node_exporter | > CPU核数×2 |

### 容器平台层
| 指标 | 采集方式 | 告警阈值 |
|------|----------|----------|
| Pod重启次数 | kube-state-metrics | > 3次/小时 |
| Pod内存使用率 | cAdvisor | > 80% |
| Node状态 | kube-state-metrics | NotReady > 1分钟 |
| PVC使用率 | kubelet | > 80% |
| Deployment副本偏差 | kube-state-metrics | 期望≠实际 |

### 应用层
| 指标 | 采集方式 | 告警阈值 |
|------|----------|----------|
| HTTP错误率 | 应用metrics | > 5% 持续3分钟 |
| 响应时间P99 | 应用metrics | > 2秒 |
| QPS | 应用metrics | < 基线50% |
| 错误日志数 | Loki | > 100条/分钟 |
