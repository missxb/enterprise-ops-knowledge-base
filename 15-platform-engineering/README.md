# 项目十四：平台工程（Internal Developer Platform）

## 项目背景

构建内部开发者平台（IDP），为开发团队提供自助式基础设施服务，提升开发效率。

## 平台架构

```
┌─────────────────────────────────────────────────────────┐
│                    开发者门户 (Backstage)                 │

│  │ 服务目录  │  │ 模板中心  │  │ 文档中心  │              │
│  │ 技术文档  │  │ API目录   │  │ 监控面板  │              │
│  └──────────┘  └──────────┘  └──────────┘              │
└────────────────────────┬────────────────────────────────┘
                         │
┌────────────────────────┼────────────────────────────────┐
│                    自助服务层                             │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐              │
│  │ 环境申请  │  │ 数据库申请│  │ 中间件申请│              │
│  │ 权限申请  │  │ 证书申请  │  │ 域名申请  │              │
```
