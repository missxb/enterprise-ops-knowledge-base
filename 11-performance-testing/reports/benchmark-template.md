## 6. 性能瓶颈分析

### 6.1 瓶颈识别

| 瓶颈 | 表现 | 原因 | 影响 |
|------|------|------|------|
| 数据库连接池 | 高并发下连接等待 | 默认连接池过小 | TPS 上不去 |
| GC 停顿 | 周期性响应时间飙升 | 大对象分配 | P99 偏高 |
| 线程阻塞 | CPU 利用率低但 RT 高 | 慢 SQL | 吞吐量低 |

### 6.2 慢 SQL 分析

```sql
-- 慢查询 #1: 全表扫描
SELECT * FROM orders WHERE status = 'pending';
-- 优化: 添加索引 idx_orders_status

-- 慢查询 #2: 大表 JOIN
SELECT o.*, i.name FROM orders o JOIN items i ON o.item_id = i.id;
-- 优化: 添加覆盖索引, 考虑读写分离
```

## 7. 优化建议

### 7.1 应用层优化

| 优化项 | 预期效果 | 优先级 |
