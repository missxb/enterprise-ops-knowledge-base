# 项目五：企业安全加固

## 项目背景

为公司基础设施和应用系统进行全面安全加固，满足等保2.0三级要求，防范常见攻击。

## 加固清单

### SSH 加固（必做）
- [ ] 修改默认端口
- [ ] 禁止 root 登录
- [ ] 仅密钥认证
- [ ] 配置 fail2ban
- [ ] 限制登录 IP

### 系统加固（必做）
- [ ] 内核安全参数
- [ ] 文件权限收紧
- [ ] 审计日志开启
- [ ] 服务最小化
- [ ] 定时漏洞扫描

### 网络加固（必做）
- [ ] 安全组最小化
- [ ] WAF 部署
- [ ] DDoS 防护
- [ ] VPN 接入
- [ ] 网络分段隔离

### 应用加固
- [ ] HTTPS 强制
- [ ] 安全 Headers
- [ ] 输入校验
- [ ] API 限流
- [ ] 依赖漏洞扫描

### AK/密钥管理（高优先级）
- [ ] AK 轮换策略
- [ ] 密钥管理服务（KMS/Vault）
- [ ] AK 泄露检测
- [ ] 最小权限原则
