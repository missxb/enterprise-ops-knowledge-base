# 项目一：企业级服务器跨云迁移（阿里云→腾讯云）

## 项目背景

某公司业务系统部署在阿里云华东1（杭州）Region，因业务扩展和成本优化需求，需要将以下资源迁移至腾讯云广州区域：
- 15 台 ECS（2台Web、3台App、2台DB、2台Redis、1台MQ、5台中间件）
- RDS MySQL 主从集群（500GB数据量）
- Redis 集群（6节点，128GB内存）
- OSS 存储桶（约 2TB 文件）
- SLB 负载均衡 + 域名切换

## 迁移策略

### 分阶段迁移计划

| 阶段 | 内容 | 周期 | 风险等级 |
|------|------|------|----------|
| P0 | 环境准备 & 网络打通 | 第1周 | 低 |
| P1 | 数据库迁移（DTS/自建同步） | 第2周 | 高 |
| P2 | 应用服务器迁移 | 第3周 | 中 |
| P3 | 文件存储迁移 | 第3周 | 中 |
| P4 | 灰度切流 & 验证 | 第4周 | 高 |
| P5 | 全量切换 & 回滚预案 | 第5周 | 高 |
