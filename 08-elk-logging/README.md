# 项目七：ELK 日志收集与分析系统

## 项目背景

搭建统一日志平台，实现日志的实时采集、存储、检索、分析和告警。

## 架构设计

```
┌─────────────────────────────────────────────────────────────┐
│                        日志源                                │
│  ┌────────┐ ┌────────┐ ┌────────┐ ┌────────┐ ┌────────┐   │
│  │ Nginx  │ │  App   │ │ MySQL  │ │  K8S   │ │ System │   │
│  │ 日志   │ │ 日志   │ │ 慢查询 │ │ Pod日志│ │ syslog │   │
│  └───┬────┘ └───┬────┘ └───┬────┘ └───┬────┘ └───┬────┘   │
└──────┼──────────┼──────────┼──────────┼──────────┼──────────┘
       │          │          │          │          │
       ▼          ▼          ▼          ▼          ▼
┌─────────────────────────────────────────────────────────────┐
│                    采集层 (Filebeat/Fluentd)                 │
└────────────────────────────────┬────────────────────────────┘
                                 │
                                 ▼
┌─────────────────────────────────────────────────────────────┐
│                    缓冲层 (Kafka)                            │
│  解耦采集与存储，削峰填谷，保证数据不丢失                      │
└────────────────────────────────┬────────────────────────────┘
                                 │
                                 ▼
┌─────────────────────────────────────────────────────────────┐
│                    处理层 (Logstash)                         │
│  解析、过滤、富化、格式化                                     │
└────────────────────────────────┬────────────────────────────┘
                                 │
                                 ▼
┌─────────────────────────────────────────────────────────────┐
│                    存储层 (Elasticsearch)                     │
│  热温冷分层存储，ILM 生命周期管理                              │
└────────────────────────────────┬────────────────────────────┘
                                 │
                                 ▼
┌─────────────────────────────────────────────────────────────┐
│                    展示层 (Kibana)                           │
│  日志检索、可视化、告警、报表                                  │
└─────────────────────────────────────────────────────────────┘
```

## 目录结构

