# Slo Sli Sla

> 本文档正在完善中，以下是核心内容

## 概述

SLO/SLI/SLA 是 SRE 的核心实践，通过量化可靠性指标来平衡产品迭代速度和系统稳定性。

## 架构

```
SLI (指标) → SLO (目标) → 错误预算 → 决策
```

## 快速部署

```
SLI 示例：
- 可用性 = 成功请求数 / 总请求数
- 延迟 = P99 < 500ms 的请求比例
- 正确性 = 正确响应数 / 总响应数

SLO 示例：
- 可用性 SLO: 99.9% (每月允许宕机 43.8 分钟)
- 延迟 SLO: 99% 的请求 < 200ms

错误预算 = 1 - SLO
- 99.9% SLO → 0.1% 错误预算 → 每月 43.8 分钟
```

## 最佳实践

1. 从关键服务开始定义 SLO
2. 错误预算耗尽时冻结发布
3. 定期回顾和调整 SLO
4. 用 SLO 驱动技术投资决策
