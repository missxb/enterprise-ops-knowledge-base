# 分支策略

## Git Flow

适合有固定发布周期的项目：

```
main ──────────────────────────────────────▶
  │                                    ▲
  ├── develop ──────────────────────┤
  │     ├── feature/xxx ────────────┤
  │     ├── feature/yyy ────────────┤
  │     │                           │
  │     └── release/1.0 ────────────┘
  │           │
  │           └── hotfix/xxx ────────┘
```

## Trunk Based Development

适合持续部署的项目：

```
main ──────●──────●──────●──────●──────●──────▶
           │      │      │      │
           ▼      ▼      ▼      ▼
         feature short-lived branches (< 2 days)
```

## 推荐策略

| 团队规模 | 发布频率 | 推荐策略 |
|----------|----------|----------|
| 小团队 (<5人) | 每天 | Trunk Based |
| 中团队 (5-20人) | 每周 | 简化 Git Flow |
| 大团队 (>20人) | 按需 | Git Flow |
