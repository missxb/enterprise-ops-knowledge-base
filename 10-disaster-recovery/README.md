# 项目九：灾难恢复与业务连续性

## 项目背景

建立完整的灾难恢复体系，确保在各种故障场景下业务可快速恢复。

## RTO/RPO 目标

| 系统级别 | RTO | RPO | 备份策略 | 恢复策略 |
|----------|-----|-----|----------|----------|
| 核心系统 | < 15分钟 | 0（零丢失） | 实时同步 | 热备自动切换 |
| 重要系统 | < 1小时 | < 5分钟 | 增量备份+binlog | 温备手动切换 |
| 一般系统 | < 4小时 | < 1小时 | 每日全量+增量 | 冷备恢复 |
| 非关键系统 | < 24小时 | < 24小时 | 每日全量 | 从备份恢复 |
