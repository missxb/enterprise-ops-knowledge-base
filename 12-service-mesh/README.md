# 项目十一：Service Mesh（Istio）

## 项目背景

在 K8S 集群上部署 Istio Service Mesh，实现服务治理、流量管理、安全通信、可观测性。

## 架构

```
┌─────────────────────────────────────────────────────────┐

│  │ Pilot    │  │ Citadel  │  │ Galley   │              │
│  │ (流量)   │  │ (安全)   │  │ (配置)   │              │
│  └──────────┘  └──────────┘  └──────────┘              │
└────────────────────────┬────────────────────────────────┘
                         │
┌────────────────────────┼────────────────────────────────┐
```

## 功能清单

- [x] 流量管理（金丝雀发布、A/B测试、流量镜像）
- [x] 服务安全（mTLS、认证授权、RBAC）
- [x] 可观测性（分布式追踪、指标收集、访问日志）
- [x] 故障注入（延迟注入、错误注入、熔断）
- [x] 限流熔断（Rate Limiting、Circuit Breaking）
